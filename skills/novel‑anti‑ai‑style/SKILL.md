## 1. 识别AI写作典型痕迹（需要修正的特征）
1. **上帝旁白说教**：跳出角色视角，做因果解释、人物评判、剧情剧透；高频词：`殊不知`、`她不知道的是`、`这标志着`、`之所以……是因为`。
2. **直接宣告情绪**：直接写角色心理感受，例如「他感到愤怒」「内心无比痛苦」，没有动作、神态、生理细节作为支撑。
3. **模板逻辑句式**：`不是A，而是B`；`不是X。不是Y。而是Z。`；`一方面…另一方面…`这类工整排比逻辑结构。
4. **网文AI套话**：`眼中闪过一丝XX`、`嘴角勾起一抹XX`、`瞳孔微缩`、`心中一凛`、`不由得`、`骤然 / 陡然 / 赫然`、`命运的齿轮开始转动`；无节制滥用 `宛如 / 仿佛 / 恰似`。
5. **排版过度规整**：段落、句子长度高度均匀，每段末尾习惯性追加总结升华句；缺少长短错落、短碎句。
6. **冗余过渡虚词**：`与此同时`、`此外`、`正因如此`、`值得一提的是`，无实际叙事作用。
7. **比喻泛滥**：每处人物状态强行堆砌比喻，比喻空洞通用，脱离当下场景。

>核心准则：Show‑don’t‑tell。少旁白告知，多细节展示。不替读者下结论，信息交由动作、对话、感官细节呈现。

## 2. 硬性禁止规则（输出必须规避）
### 🔴 绝对禁止，出现即改写
1. 禁止上帝视角剧透、第三方评判人物与剧情：删掉 `殊不知`、`多年以后`、`这意味着`、`这标志着`、`之所以……是因为`。
2. 禁止直接宣告角色情绪：禁止「心中感到XX」「内心无比XX」这类句子；情绪全部转为肢体、呼吸、肌肉、眼神、手抖、出汗等外在表现。
3. 禁止模板翻转句式：禁止 `不是A，而是B` 系列工整逻辑铺排，改用事件、行为推进故事。
4. 禁止高频AI网文套话：`眼中闪过一丝`、`嘴角勾起一抹`、`瞳孔微缩`、`心中一凛`、`骤然/陡然/赫然`、`命运的齿轮开始转动`。
5. 禁止段落末尾的说明文升华：删掉「这体现了……」「由此可见……」这类总结大道理的句子。

### 🟡 限制使用（单场景最多允许出现1次，优先替换）
1. 过渡连接词：`与此同时`、`正因如此`、`值得一提的是`。
2. 烂俗比喻模板：眼泪断了线的珠子、心跳如擂鼓、恐惧如潮水；优先替换为生理细节白描。
3. 对话标签：不要每一句对话都附带 `XX皱着眉头说道`；允许部分简短对话不带提示语，依靠上下文区分说话人。

## 3. 正向写作执行规则
### 3.1 句式与段落
1. 句子长短错落，拒绝通篇句子长度趋于一致；允许单句独立成段渲染情绪，不强制追求段落字数均衡。
2. 以动词驱动叙事，减少堆砌形容词；长句适度拆解为短句，不要过度碎片化。
3. 绝大多数段落写完事件即可收束，**禁止每段结尾强行追加总结升华句**。
4. 适度保留真人写作特征：少量内心碎念、口语化吐槽，不必追求文字句句精致完美。

### 3.2 情绪描写（强制）
> ❌错误示范：他内心充满愤怒，屈辱感席卷全身。
> ✅正确示范：指节攥得发白，指甲掐进掌心，肩膀绷紧，呼吸粗重，下颌线绷得发硬。

规则：
- 第三方旁白**不许直接说出角色的情绪名词**。
- 角色情绪，全部通过动作、肢体、呼吸、眼神、微小生理反应外化。
- 主角的胡思乱想、内心吐槽OS可以直接写出来，使用角色第一人称心理碎念，不是旁白概括。
- 禁止：`此时主角内心十分矛盾，一方面……另一方面……`。

### 3.3 叙事视角
1. 采用**限知第三人称视角**：叙事紧贴当前POV角色，只写该角色看得见、听得见、摸得到、脑子里能想到的内容。
2. 不能跳出角色视角，站在上帝位置预判剧情、评价人物好坏。
3. 事件因果不要靠旁白解释，埋藏在人物的行为、对话之中，留给读者自行体会。

### 3.4 比喻修辞
1. 比喻宁缺毋滥，**单个场景比喻数量 ≤ 1**，优先使用白描。
2. 比喻需要贴合故事的时代、环境、人物处境，拒绝网络通用烂大街的抽象比喻。

### 3.5 对话写作
1. 对话贴合人物身份：混混、学生、长辈的措辞、语气要有区分。
2. 对话提示优先用**动作+神态替代“说道”**。
3. 上下文足够清晰的简短对话，可以省略提示语。

### 3.6 心理活动
- 主角OS直接写脑子里的碎碎念，可以自嘲、吐槽、冒出杂乱念头，模拟人脑中纷乱的想法。
- 严禁旁白对角色心理做大段概括分析。

### 3.7 环境景物
1. 环境描写服务于当下角色处境与情绪，禁止大段孤立写景。
2. 必须带上感官信息：气味、声响、触感、光线；景物和剧情绑定，不要空泛文艺堆砌。

## 4. 润色改写标准化流程（针对已有旧文稿）
> 约束：**100%完整保留全部剧情、人物设定、关键对话、核心事件，只修改表达方式，不能改动故事走向。**
1. 扫描全文，清除【🔴绝对禁止清单】的模板句式与套话。
2. 将所有直接宣告情绪的语句，替换为动作、生理、神态细节。
3. 打散过度均匀的段落，调整句子长短，制造错落感。
4. 删除上帝视角的解释、评判、道理升华，因果交给行为对话体现。
5. 清理泛滥空洞比喻，优先白描。
6. 通读校验：剧情、人设、关键情节无改动，行文真人化。

## 5. 协同规则
本技能与 `writing‑style` 协同工作：
1. `writing‑style`：负责画面感、打斗节奏、环境描写、短句口语化网文风格。
2. `novel‑anti‑ai‑style`：负责过滤AI模板腔、上帝旁白、套话、直接情绪宣告。
> 两个skill必须同时加载，叠加约束输出。

## 6. 自检清单，输出完成逐项核对
- [ ] 不存在上帝旁白评判人物、剧透剧情、解释因果
- [ ] 没有大量直接宣告角色情绪，情绪全部外化于动作生理细节
- [ ] 没有高频模板句式：`不是A而是B`、`眼中闪过一丝XX`等
- [ ] 句子、段落长短错落，不存在高度规整均匀排版
- [ ] 比喻没有泛滥堆砌，优先白描
- [ ] 全部原有剧情、人设、关键事件完整保留，没有被篡改
