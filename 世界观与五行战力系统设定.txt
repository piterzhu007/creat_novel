# 现代向世界观与五行战力系统（重设版·终稿）

> 本稿根据《问题与建议》对前稿作出如下重大调整：
> 1. **只有主角白夜一人拥有异能**。人类阵营没有修行者、没有异能者、没有修行世家/古武隐门/五行宗；人类只能通过科技强化自身、使用武器与装备对抗超凡。
> 2. 全书仅存**三大主体阵营**：主角（地球意志/五行化身）、人类（内部复杂、派系林立）、外来魔物（灭世之源及其眷属）。
> 3. 一切"修行世家""古武隐门""五行宗""异能者登记"等设定全部删除；原"天衡""镇岳司"重新定位为**人类科技机构**（研究超凡、镇压魔物、掩盖真相），不再涉及任何人类异能者管理。
> 4. 遵循《问题与建议》的写作原则：人物与情节优先，环境描写只作点缀；农村/身世背景一笔带过，不铺陈、不注水。

## 〇、设定总纲（核心原则）

本设定服务于主角「白夜」——地球意志 / 五行元素化身——在现代社会收集失散力量、对抗外来魔物、周旋于人类阵营的故事。

四条核心原则（所有衍生设定不得与之冲突）：

1. **现代为表，玄幻为里**：世界表面是当代都市社会，暗处是魔物、科技、地球意志三方角逐的隐秘世界；绝大多数普通人终生不知超自然之事。
2. **五行贯通三方**：五行元素之力是地球意志的"语言"。主角（唯一异能者）、魔物（魔能侧）、人类造物（造物侧）三方共用同一套可比较的战力标尺——这是全书战力比较的基础。
3. **力量即代价**：白夜每收集一份力量，自身越强，但封印魔物的枷锁越松——成长与危机互为表里，这是暗线引擎。
4. **造物有上限**：人类科技造物的战力巅峰只能达到主角巅峰（太一境）的约五成，即归真境。科技永远无法替代地球意志，只能逼近、借用、对抗，不能超越。

## 第一篇 世界观

### 1.1 世界定位与时代背景

- **世界类型**：衍生世界——以现实地球为底本，叠加一层"灵能真实"的平行现代世界。
- **时间**：当代（约21世纪二三十年代，科技略高于现实，有可控核聚变、强人工智能、纳米与基因工程等前沿技术）。
- **表面社会**：与真实世界无异——城市、乡村、学校、互联网、国际政治、资本市场照常运转。
- **隐秘社会**：魔物、灵能事件被各国高层与国际组织严密掩盖（代号「静默原则」）。普通民众接触到的异象会被统一解释为自然灾害、事故或集体幻觉。

### 1.2 地理环境与灵脉体系

地球不只是物质星球，更是一个活的意识体——「地球意志」。其生命能量以五行为载体，沿地下的「灵脉」网络流动，如同星球的血脉。

- **灵脉**：五行灵气在地壳中的主干与支流。灵脉交汇处为「灵眼」，灵气最浓，也最易被魔物污染。
- **命种之地**：白夜前世封印魔物时，将五行之力打散为五枚「命种」，分别沉入五处地脉绝地。这五地由此形成特殊地貌：
  - 水之命种 → 极渊深潭（深海海沟 / 内陆天坑暗河）
  - 木之命种 → 万灵之森（原始雨林 / 生命网络枢纽）
  - 火之命种 → 焚心火山（活火山地脉核心）
  - 土之命种 → 大地母窟（地下溶洞 / 生命复苏之地）
  - 金之命种 → 百炼矿脉（地底金属矿脉 / 古战场埋骨地）
- **侵蚀区**：被魔能污染的地带。生态异变、生物狂乱、人心失守。以"灰斑"形式在全球缓慢扩张，前期被官方包装为"生态灾害""新型污染"。

### 1.3 隐秘社会与势力格局

> 核心原则：**人类没有异能者**。人类的一切超凡应对能力全部来自科技、装备、武器与组织动员。隐秘社会本质上是"懂真相的科技官僚 + 军工资本 + 军队"与魔物的博弈。

- **人类反派「普罗米修斯集团」**：跨国军工–财团复合体。主张"以科技夺神权"，暗中研究魔能并武器化，甚至不惜以活人实验制造"强化士兵"，是前期对抗主角的主要人类势力。
- **魔物阵营**：外来大BOSS（灭世之源）的眷属与被侵蚀者。BOSS被封印于地核附近的"无间封印"，其魔能通过封印裂缝渗透地表，制造魔物、蛊惑人类内鬼。
- **人类内部复杂性**：天衡（维稳/护世）、各国政府（各怀利益）、普罗米修斯集团（夺神权）、普通民众（被蒙蔽）之间立场分裂、明争暗斗。人类并非铁板一块，主角不得不在其中周旋、结盟、对抗。

### 1.4 三大阵营

| 阵营 | 力量本源 | 代表 | 特点 |
|---|---|---|---|
| 主角 | 五行元素（地球意志） | 白夜（唯一异能者） | 自然、可修行、有上限（太一境），全书唯一掌控五行神通者 |
| 人类 | 科学技术（人类造物） | 天衡、各国军队、普罗米修斯集团 | 可量产、无修行门槛、有上限（归真境≈主角五成）、内部复杂 |
| 外来魔物 | 侵蚀之力（外来魔物） | 灭世之源、魔物、被侵蚀者 | 污染、变异、寄生于生灵 |

> 说明：原稿中的"灵能侧（修行者/异能者/五行宗）"已删除。灵能侧仅剩主角白夜一人。人类再强大的个体，也只是"科技强化的人"，不是异能者。只有主角才能拥有异能，人类阵营只能通过使用科技强化自身和使用武器，因此也就没有什么修行世家。只有三个主体阵营：主角、人类（内部复杂）、外来魔物。

## 第二篇 五行战力系统

### 2.1 力量本源三分

全书所有超凡力量归入三大体系，统一以「能级」衡量，使三方可在同一标尺下比较强弱。

- **灵能（主角专属）**：源自地球意志的五行元素之力，正、纯、可再生，可修行提升。**只有白夜一人拥有**。
- **魔能（魔物侧）**：源自外来魔物的侵蚀之力，邪、浊、寄生性，以污染生灵为扩张手段。
- **造物能（人类侧）**：人类以科技模拟、转化、对抗灵能/魔能的产物（武器、机甲、强化士兵、纳米风暴等）。

### 2.2 通用度量：能级与"格"

- **能级**：抽象的能量总量，用于横向比较。每提升一个大境界，能级约呈数量级增长（详见各境参照）。
- **格**：力量的"位阶/权限"。地球意志之"格"高于魔物与人类造物，故同能级下，灵能（高格）往往克制魔能与造物能。这也是造物侧无法超越灵能巅峰的深层原因——科技能堆积能级，却无法复制"格"。

## 第三篇 灵能侧：五行九境（主角白夜专属）

### 3.1 九境三阶总表

五行修行体系共分**九境三阶**，古风易懂，由低到高（此体系为白夜一人专属）：

| 阶 | 境 | 名称 | 一句话定位 |
|---|---|---|---|
| 下三境（凡阶） | 一境 | **启灵** | 灵根觉醒，凡体超凡 |
| | 二境 | **凝元** | 元力凝聚，初显外放 |
| | 三境 | **通玄** | 神通初成，元素显形 |
| 中三境（玄阶） | 四境 | **化意** | 一念化形，领域雏形 |
| | 五境 | **归真** | 五行归元，开始融合 |
| | 六境 | **合道** | 身合天道，引动天象 |
| 上三境（神阶） | 七境 | **太虚** | 超越凡尘，触及本源 |
| | 八境 | **无垢** | 万物归净，五行圆满 |
| | 九境 | **太一** | 五行归一，地球意志本体 |

小境界：每境分 **初期 / 中期 / 后期 / 大圆满** 四重。

### 3.2 各境详解（含现实战力参照）

**一境·启灵（凡阶）**
- 概述：灵根觉醒，能感知天地游离的五行灵气；体质脱胎换骨。
- 能力：力碎砖石、疾追奔马、感官敏锐（夜视、闻微）、自愈初显。
- 参照：单兵之王，相当于全副武装的精锐特种兵。

**二境·凝元（凡阶）**
- 概述：丹田/命轮内凝出"元力"，五行之力可初步外放。
- 能力：掌心凝火苗、水流、土刺、金刃、藤蔓；可硬抗手枪/步枪子弹；隔空御物。
- 参照：一支全副武装的战术小队 / 主战坦克。

**三境·通玄（凡阶）**
- 概述：神通初成，五行之力可塑成稳定的元素形态并持续作战。
- 能力：大范围元素攻击（火墙、水龙卷、石巨人、金属风暴、荆棘之林）；可短距飞行、高速移动；初步硬抗重武器。
- 参照：一支合成营（数百人+装甲+火炮）/ 一艘驱逐舰的火力。

**四境·化意（玄阶）**
- 概述：一念化形、意到力至，元素如臂使指；可展开"领域"雏形。
- 能力：领域内改写局部环境（火域、水界、土阵）；元素拟态分身；元素具现为活物。
- 参照：一支集团军 / 战略轰炸机编队。人类常规军力到此已难正面压制。

**五境·归真（玄阶）——人类造物巅峰**
- 概述：五行反本归元，开始两两融合，可短暂改变局部自然规律。
- 能力：双元素融合神通；短暂改写物理法则（改变重力、凝滞时间一瞬、扭转局部因果）；一人可屠一城。
- 参照：核武器级 / 天灾（地震、海啸）。**人类造物能达到的最高境界。**

**六境·合道（玄阶）**
- 概述：身合天道、言出法随，可引动天象。
- 能力：呼风唤雨、移山填海；三元素融合；一人影响一国之地。
- 参照：超越人类全部常规武力总和。

**七境·太虚（神阶）**
- 概述：超越凡尘，触及世界本源，获得地球意志之"格"的投影。
- 能力：四元素融合；全球感知；一念影响大陆级地脉。
- 参照：行星级力量。

**八境·无垢（神阶）**
- 概述：万物归净，五行圆满，可重塑地表。
- 能力：五行融合；净化一切侵蚀；重铸山川河海。
- 参照：行星级巅峰，无限接近地球意志本体。

**九境·太一（神阶）——主角巅峰**
- 概述：五行归一，即为地球意志本体，掌创世灭世之力。
- 能力：五行归一，掌控整个星球的生死循环、生态兴衰、物种存亡。
- 参照：地球意志本身（文明级 / 行星神级）。

### 3.3 五行属性详解

#### 水（坎卦）——变化与净化
- 核心：至柔至变，洗尽污浊。
- 能力树：
  - 基础：形态转换（气/液/固）、身化流水、凝水成兵。
  - 进阶：绝对零度（冰）、深海压强、大范围净化（洗去魔能侵蚀、破除幻术迷障）。
  - 巅峰：生命之雨（大规模治愈）、沧海化形（以水拟万物）。
- 性格隐喻：适应、包容、明辨是非（白夜性格底色）。

#### 木（震/巽卦）——联通万物
- 核心：生发不息，一脉相通。
- 能力树：
  - 基础：操控植物、催生缠绕、生命感知。
  - 进阶：万物之心（接入全球生命网络，读取/传递信息）、一念花开。
  - 巅峰：生命嫁接（将自身生机渡给他人/大地）、万灵共鸣（号令亿万生灵）。
- 性格隐喻：共情、联结、胸怀天下。

#### 火（离卦）——极致破坏
- 核心：焚尽一切，至刚至烈。
- 能力树：
  - 基础：燃烧、爆炸、高温等离子。
  - 进阶：净化之焰（焚尽侵蚀却护住无辜——火亦有净的一面）、太阳真火、核聚变级烈焰。
  - 巅峰：焚天（蒸发海洋、熔断山脉）。
- 性格隐喻：抗争精神、怒火与守护之心并存。

#### 土（坤/艮卦）——治愈与生命
- 核心：厚德载物，生生不息。
- 能力树：
  - 基础：大地防御、生命恢复、治愈创伤。
  - 进阶：大地之母（范围治愈与守护）、重塑生机（恢复被侵蚀的生态）。
  - 巅峰：起死回生（有条件，见下）。
- 起死回生的条件：只能救"魂未散、体尚存、死因非命格已尽"者；须以白夜自身寿命或命环之力为代价；被魔能彻底侵蚀者不可救。
- 性格隐喻：温柔、承受、牺牲。

#### 金（兑/乾卦）——锐不可当、坚硬无比
- 核心：无坚不摧，金刚不坏。
- 能力树：
  - 基础：金属掌控、刃化肢体、坚硬护甲。
  - 进阶：万剑归宗、绝对防御、法则之刃（切割空间/斩断因果）。
  - 巅峰：金刚不灭身、一念万兵（掌控全球金属）。
- 性格隐喻：宁折不弯、百炼成钢。

### 3.4 相生相克与融合机制

**相生（顺行，融合效率高、稳定）**：木生火 → 火生土 → 土生金 → 金生水 → 水生木。
**相克（逆行，融合威力大、难驾驭）**：木克土 → 土克水 → 水克火 → 火克金 → 金克木。

**融合总则**：
- 相生融合：消耗小、稳定，适合持续作战与守护。
- 相克融合：爆发强、反噬大，适合绝境搏命。
- 融合的运用程度取决于白夜的境界与已收集的命种数量（见第七篇）。

**双元素融合示例表**：

| 组合 | 类型 | 名称 | 效果 |
|---|---|---|---|
| 水+木 | 相生 | 生命之泉 | 大范围治愈+净化 |
| 木+火 | 相生 | 燎原之焰 | 持续燃烧、焚尽侵蚀 |
| 火+土 | 相生 | 熔岩大地 | 熔岩领域、攻防一体 |
| 土+金 | 相生 | 万仞之城 | 金属壁垒+大地重力 |
| 金+水 | 相生 | 寒霜刃狱 | 冰刃风暴、锐利+冻结 |
| 水+火 | 相克 | 阴阳激流 | 蒸汽爆炸/冷热交替撕裂 |
| 火+金 | 相克 | 熔金焚天 | 超高温破甲+金属风暴 |
| 金+木 | 相克 | 铁树荆棘 | 金属荆棘、束缚+切割 |
| 木+土 | 相克 | 根裂大地 | 根系破岩、瓦解防御 |
| 土+水 | 相克 | 陷世泥沼 | 困敌、吞噬、窒息 |

**三元素及以上**：
- 三元素（如木+火+土 = "复苏之焰"——燃烧生命力反哺大地的治愈之火）已是玄阶高段的标志。
- 四元素 = 神阶（太虚境）。
- 五行归一 = 太一境（地球意志本体），可重新定义星球生态。

## 第四篇 魔能侧：侵蚀九阶（魔物 / 被侵蚀者）

### 4.1 侵蚀机制

魔能是**寄生性力量**，通过与生灵接触而扩张，具有三重侵蚀：
- **神智侵蚀**：使人狂乱、偏执、失忆、杀戮欲。
- **肉体侵蚀**：生物异变、魔化、异形化。
- **地脉侵蚀**：污染灵脉，制造"侵蚀区"，使生态与人心整体腐化。

侵蚀不可逆，除非被"水之净化"或"无垢境"力量彻底清除。

### 4.2 九阶详解（与灵能九境一一对应）

| 阶 | 名称 | 描述 | 对应灵能境 |
|---|---|---|---|
| 一阶 | **侵染** | 心智初扰：噩梦、情绪失控、微弱的杀戮欲，外表正常 | 启灵 |
| 二阶 | **蚀骨** | 肉体变异：力量暴增、皮肤硬化/生鳞角，仍残留人性 | 凝元 |
| 三阶 | **魔化** | 完全魔物化，失去人性，沦为无脑魔物 | 通玄 |
| 四阶 | **魔灵** | 有智慧的魔物，可统领低级魔物、设局谋略 | 化意 |
| 五阶 | **魔将** | 一城之灾：可污染整座城市的地脉与生灵 | 归真 |
| 六阶 | **魔王** | 一国之力：可掀起全国性灾变 | 合道 |
| 七阶 | **魔主** | 大陆级：污染整片大陆 | 太虚 |
| 八阶 | **天魔** | 全球级：污染全球生态 | 无垢 |
| 九阶 | **灭世之源** | BOSS本体，外来魔物，侵蚀之力可毁灭地球 | 太一 |

## 第五篇 造物侧：人类科技 T 级

### 5.1 T 级详解（人类以科技模拟/对抗超凡力量）

> 人类没有异能。人类的一切超凡手段都来自科技：强化个体（外骨骼、基因工程、义体）、武器（能量武器、机甲、天基武器）、工程（纳米、气候）。强化士兵仍是"人+科技"，不是异能者。

| 级 | 名称 | 代表 | 对应灵能境 |
|---|---|---|---|
| T1 | 单兵级 | 动力外骨骼、能量步枪、仿生义体、基因强化战士 | 启灵~凝元 |
| T2 | 战术级 | 无人战车、战斗无人机群、磁轨炮、定向能武器 | 凝元~通玄 |
| T3 | 战略级 | 反异能机甲、天基能量武器、电磁脉冲网、生物兵器 | 通玄~化意 |
| T4 | 天灾级（造物巅峰） | 核武器、气候武器、纳米风暴、行星工程 | 化意~归真 |

**造物上限铁律**：人类造物能级可堆叠至归真境（第五境），但永远无法触及合道境（第六境）及以上——因为科技能复制"能级"，复制不了地球意志之"格"。归真境 = 主角巅峰（太一境）的约五成，与总纲原则一致。

### 5.2 反异能武器（针对白夜的造物）

白夜能力暴露后，普罗米修斯集团与部分国家启动"弑神计划"，研发针对性武器：
- **灵能抑制场**：干扰五行之力运转，压制异能外放。
- **灵能锁定网**：侦测、追踪、锁定灵能波动。
- **元素克制弹**：针对五行属性研发（如对火用水基凝胶弹、对金用超高温熔解弹）。
- **基因战士**：注入魔能/灵能基因的人造超凡士兵，多不稳定、易魔化（这是"科技强化"，仍非异能者）。
- **纳米风暴**：以纳米机械群吞噬、瓦解元素形态。
- **天基"净世"武器**：人类最后底牌，可对地表进行"归真境"级打击（代价是生态毁灭）。

## 第七篇 主角命轮与力量收集

### 7.1 命轮设定（白夜专属）

白夜的本源是「**五行命轮**」，由五道命环组成，对应五行。每收集一枚命种，点亮一道命环，战力暴涨一个大境界，并解锁对应元素的完整能力树与融合权限。

- 一命环：水 → 点亮后从凡人跨入凝元境（觉醒异能）。
- 二命环：木 → 通玄境。
- 三命环：火 → 化意境。
- 四命环：土 → 合道境。
- 五命环：金 → 太虚境。
- 五行归一轮满 → 可冲击无垢、太一。

### 7.2 五行命种的收集条件（各不相同，须历劫方能得）

| 命种 | 所需境界/心性条件 | 触发方式（剧情钩子） |
|---|---|---|
| **水** | 向死而生：濒死而不怨、心怀善念渡死劫 | 开端被霸凌迫害至死，绝境中保住本心，于"生死之间"觉醒（已发生） |
| **木** | 无私共鸣：放下自我、舍身救护他人/万灵 | 为救众人甘愿以身犯险，倾听万物之声 |
| **火** | 守护之怒：为守护而燃起不屈怒火，而非为私欲破坏 | 目睹所护之人/之物受难，于绝境中爆发 |
| **土** | 承生命之重：承受失去与牺牲之痛，仍选择守护生命 | 重大失去（伙伴/重要之人牺牲）后，依然站起 |
| **金** | 百炼成钢：历千锤百炼而心志不折、宁折不弯 | 长期磨难与挫折中淬炼出钢铁意志 |

**设计逻辑**：五枚命种的收集条件分别对应白夜五段人物弧光——水的"明辨"、木的"大爱"、火的"抗争"、土的"牺牲"、金的"坚韧"，使战力成长与性格成长同频。

### 7.3 成长与封印联动（暗线引擎）

- 白夜前世以自身全部五行之力为锁，将灭世之源封印于地核附近（「无间封印」）。
- **收集的力量越多 = 解开的锁越多 = 封印越松**。
- 魔物阵营因此**有意引导白夜收集命种**：送机缘、设危局，让白夜"不得不"变强，实则一步步为自己解封。
- 全书张力来源：白夜每变强一分，末日就近一分；但他若不收集力量，又无法应对不断升级的危机——这是一个无解的成长悖论，最终须在转折阶段找到破局之法（以"格"补"量"，或以封印之外的代价重建枷锁）。

## 第九篇 写作纪律（据《问题与建议》确立）

1. **人物与情节第一**：每一段情节只围绕一件详细完整的事件展开，用事件突出人物性格；环境描写、场景描写只作点缀，绝不成为主体。
2. **拒绝生硬铺垫**：不在开头无理由地抛设定（如"五色石头"），超自然元素必须从真实、有张力的日常冲突中自然浮现。
3. **身世一笔带过**：农村/孤儿/失忆等背景用一两句话交代即可，不铺陈、不注水。
4. **章末留钩子**：每个叙事单元收束时，埋下下一阶段的悬念。

（本设定为世界观与战力系统总纲，人物、分卷、章节大纲另见《小说提纲》与长期记忆。所有设定内在自洽，章节撰写者须以本文件为准绳。）
